# Datasheets

Reference datasheets for the EEPROM devices used or evaluated in the 8-bit computer project.

Current files:

- `AT28C64B.pdf` — AT28C64/AT28C64B 64 Kbit parallel EEPROM reference.
- `28C16 (Obsolete).pdf` — legacy 28C16 EEPROM reference retained for comparison with the earlier device choice.

Project-specific ISA, schematics, and implementation notes live elsewhere in the repository.
