# Hardware

This directory contains exported schematic documentation for the 8-bit computer hardware.

The public snapshot includes PDF schematics for the complete system and major functional modules, including the ALU, A/B registers, clock, control logic, instruction register, memory-address register, output module, program counter, and RAM.

PCB schematic capture and routing were completed in KiCad; the repository currently publishes the exported schematic set rather than the full KiCad project source.

See the repository root README for current build status and the broader hardware/software workflow.
